## Open source

Tools I wrote for my own work and published:

- [afk-agents](https://github.com/nahuelsoria/afk-agents): scaffold and manage unattended agents with cron, bash, Telegram and the Claude CLI. No dependencies.
- [prose-slop](https://github.com/nahuelsoria/prose-slop): a linter that flags AI-sounding prose before you publish it. English and Spanish, no dependencies.
- [capgauge](https://github.com/nahuelsoria/capgauge): reads Claude Code and Codex transcripts locally and tells you when you will hit the weekly limit.
- [askedthrice-cli](https://github.com/nahuelsoria/askedthrice-cli) and [llmaudit-mcp](https://github.com/nahuelsoria/llmaudit-mcp): a CLI and an MCP server to check whether AI assistants recommend a brand.
- [prod-playwright-audit](https://github.com/nahuelsoria/prod-playwright-audit): a skill for coding agents that audits the critical flows of a deployed web app without changing production data.
- [solari-identity-guard](https://github.com/nahuelsoria/solari-identity-guard): proves which account a browser profile holds before an agent acts on it.
